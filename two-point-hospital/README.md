# Two Point Hospital — Knowledge Base

A comprehensive reference and strategy compendium for **Two Point Hospital**
(Two Point Studios / Sega, 2018), covering the base game and all seven story
DLCs. Compiled July 2026 from the Two Point Hospital Fandom wiki (retrieved
via its MediaWiki API), the GameFAQs walkthrough by CityBuilderAK47 (via
Wayback Machine archives), gamepressure.com, Steam Community guides,
Wikipedia, and community sources. Each document ends with its own Sources
section; conflicting or unverifiable data is flagged inline rather than
smoothed over.

## Presentation layer

`compendium.html` is a self-contained, searchable single-page front-end over
these documents (sidebar navigation, illness quick-lookup across all 278
entries, per-section table filters, light/dark themes). Open it directly in a
browser. It is generated from the markdown by `build_compendium.py` — rerun
that script after editing any document to refresh the page.

## Known gaps

- The wiki does not publish numeric prestige/attractiveness point values per
  item, per-illness health-decay rates, or exact happiness-factor weights.
- A few numbers conflict between sources (machine upgrade strength, some
  research point costs, epidemic reward figures) — flagged inline where they
  occur.
- Two GameFAQs pages (Lower Bullocks R.E.M.I.X, Blighton 3-star layout) were
  never archived; those sections lean on wiki data.
